## How to update this file

When the corpus changes, the extract may need a new version. The version-bump rule:

- A new corpus entry that adds a load-bearing concept the extract should reference → minor version bump (v1.1, v1.2)
- A revision to an existing corpus entry that changes a claim the extract synthesizes → minor or major version bump depending on whether the claim is load-bearing
- A removal of a corpus entry the extract depends on → major version bump (v2.0)
- A pure addition that does not modify existing claims → may not require a version bump if the extract still preserves the load-bearing claims faithfully

The discipline is: *if a fine-tuning run used corpus-extract vN, that fine-tuned model carries vN's framing forward.* Cross-version comparisons must document which version was used at each stage.
